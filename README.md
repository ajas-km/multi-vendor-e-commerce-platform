# Multi-Vendor E-Commerce Platform

This is a microservices-based Multi-Vendor E-Commerce Platform.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js (Microservices)
- **Database**: MongoDB (Mongoose)

## Directory Structure
- `/frontend` - React application
- `/backend/api-gateway` - API Gateway
- `/backend/auth-service` - Authentication Service
- `/backend/user-service` - User Profile Service
- `/backend/vendor-service` - Vendor Management
- `/backend/product-service` - Product Catalog
- `/backend/cart-service` - Shopping Cart
- `/backend/order-service` - Order & Checkout
- `/backend/shared` - Shared utilities and middleware
